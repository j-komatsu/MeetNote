# MeetNote

MeetNoteは、会議の議事録を簡単に管理できるアプリケーションです。本システムはフロントエンド(Vue.js)とバックエンド(Spring Boot)で構成されており、APIを通じてデータの取得・保存・更新・削除が可能です。

---

## 技術スタック
- **フロントエンド**: Vue.js
- **バックエンド**: Spring Boot
- **通信**: REST API
- **データ形式**: JSON

---

## 機能一覧

### 1. **議事録一覧表示**
- 既存の議事録を一覧形式で表示。
- 各議事録に「編集」ボタンを配置。

### 2. **議事録詳細表示・編集**
- 選択した議事録の詳細を表示。
- タイトル、日付、内容を編集可能。

### 3. **議事録新規作成**
- 新しい議事録を作成。
- 作成後、自動で議事録詳細画面に遷移。

### 4. **議事録削除**
- 議事録を削除する機能。
- 削除後、一覧画面に遷移。

### 5. **モーダル通知**
- 保存や削除の成功時にモーダルで通知。

## APIエンドポイント

### 1. 全議事録取得
- **HTTPメソッド**: `GET`
- **URL**: `/minutes`
- **レスポンス例**:
```json
[
  {
    "id": 1,
    "title": "定例会議",
    "date": "2025-01-11",
    "content": "議題1: 進捗報告\n議題2: 次回のタスク"
  }
]
```

### 2. 議事録取得
- **HTTPメソッド**: `GET`
- **URL**: `/minutes/{id}`
- **レスポンス例**:
```json
{
  "id": 1,
  "title": "定例会議",
  "date": "2025-01-11",
  "content": "議題1: 進捗報告\n議題2: 次回のタスク"
}
```

### 3. 新規議事録作成
- **HTTPメソッド**: `POST`
- **URL**: `/minutes`
- **リクエスト例**:
```json
{
  "title": "新規議事録",
  "date": "2025-01-15",
  "content": "議題内容..."
}
```
- **レスポンス例**:
```json
{
  "id": 3,
  "title": "新規議事録",
  "date": "2025-01-15",
  "content": "議題内容..."
}
```

### 4. 議事録更新
- **HTTPメソッド**: `PUT`
- **URL**: `/minutes/{id}`
- **リクエスト例**:
```json
{
  "title": "更新された議事録",
  "date": "2025-01-16",
  "content": "更新内容..."
}
```

### 5. 議事録削除
- **HTTPメソッド**: `DELETE`
- **URL**: `/minutes/{id}`

## 注意事項
- **データ保存について**  
  バックエンドのデータは一時的に保存されます。ページリロードやサーバー再起動でデータがリセットされるため、エクスポートを忘れないようにしてください。

- **認証機能**  
  現時点では未実装です。
